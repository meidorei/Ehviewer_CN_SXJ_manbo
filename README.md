# 新增功能简介

- **本地追更**：右侧原“订阅”页已改为本地“追更”，不依赖服务器订阅，也不要求登录。支持更新计数、排序、自动基线以及 JSON 导入和导出。
- **书签更新**：书签栏可以检查全部书签或长按检查单个书签，并显示每个书签的新内容数量。
- **更新算法**：追更和书签均可选择“全局中文扫描”或逐项检查；全局扫描无法精确处理的书签会自动改为逐书签检查。
- **上次更新到这**：列表分割线使用上一次成功提交的同步边界。打开列表和清零数量不会移动分割线，只有下一次成功检查才会更新位置。
- **可控制的后台检查**：更新任务显示当前方式、来源、进度、扫描页数和完整更新时间，并支持暂停、继续和停止。
- **自动拼接中文**：开启后，普通搜索、订阅搜索、标签搜索和上传者搜索会自动添加中文语言条件；已指定语言时不会重复添加。
- **JM 号查询**：支持输入纯数字，查询漫画名称、封面、作者、标签和章节等资料。

# 本地追更

## 添加与管理

1. 在漫画列表或漫画详情中长按标签，点击“追更”即可添加；再次操作可以取消追更。
2. 本地追更不要求登录。左侧原服务器 Watched 和服务器“订阅”操作仍然保留，二者互不影响。
3. 右侧追更页的设置按钮可以进入管理页搜索或删除标签。
4. “设置 → 高级”提供“导出追更”和“导入追更”。导入 UTF-8 JSON 时可以选择“合并导入”或“替换全部”。
5. 新增或导入的标签会立即显示 `0`，并在后台自动细化到添加时刻附近的最新基线，不需要先手动检查一次。

## 检查更新

点击追更页的刷新按钮，选择方式后点击“开始检查”：

- **全局中文扫描**：最多扫描 30 页中文结果，同时匹配全部追更标签；未覆盖旧边界的标签会自动改为逐标签检查。
- **逐标签第一页**：每个标签只检查第一页，适合距离上次完整检查时间较久的情况。

检查期间再次点击刷新按钮或状态区域，可以打开统一的任务详情，查看进度、来源、扫描页数和更新时间，也可以暂停、继续或停止任务。

每个标签名前会显示 `0–20` 或 `20+`。发现新内容时，更新数和标签名之间会出现绿色圆点，例如 `3 ● artist:foo`。未打开标签时，多次检查发现的数量会继续累加；成功打开该标签并加载第一页后，数量清零为 `0`。

更新数字始终按中文内容检查，与“自动拼接中文”开关无关。打开追更列表仍会遵循该开关决定实际展示的搜索结果。

# 书签更新

1. 新增书签后立即显示 `0`，并自动建立最新基线。
2. 点击书签栏刷新按钮，可以选择“全局中文扫描”或“逐书签检查”，切换选项不会立即开始，必须点击“开始检查”确认。
3. 全局扫描可以共享已经读取的中文画廊列表；复杂关键词、模糊匹配、通配符或其他无法在本地精确判断的查询会自动改为逐书签检查。
4. 长按书签可以只检查该书签；单项检查不会覆盖书签栏的整栏检查时间。
5. 书签按更新数降序显示，相同数量保持原手动顺序。发现新内容时同样显示绿色圆点，打开书签并成功加载第一页后数量清零。
6. 明确包含非中文语言条件或不支持更新检查的特殊模式会显示原因，不会显示误导性的 `0`。

# 更新分割线

追更标签、书签和左侧服务器 Watched 聚合页使用“上次更新到这”分割线：

- 分割线上方是最近一次检查发现的新内容，线下方是检查前已经存在的内容。
- 分割线来自最近一次成功提交前的同步边界，并使用发布时间和同秒 Gallery ID 判断位置。
- 首次仅建立基线时不显示分割线，完成下一次有效检查后才会显示。
- 打开列表只会清零更新数量，不会移动分割线。
- 首页和普通临时搜索不显示更新分割线。

# 自动拼接中文

在左侧菜单中开启“自动拼接中文”后，普通搜索、订阅搜索、标签搜索和上传者搜索会自动附加中文语言条件。已经明确指定语言的搜索不会重复添加。

# JM号查询

1. 打开左侧菜单，点击“JM号查询”。
2. 点击“查询”后会显示漫画名称、封面、作者、标签、章节及服务器提供的其他资料。
3. 可以复制漫画名称，或点击“浏览器打开”前往当前 JM 网页。

JM 使用易变的内部接口。出现“JM服务暂时不可用”时，请先检查 VPN 和网络后重试；封面加载失败不会影响名称和文字资料。JM 查询使用独立的临时 Cookie，不会读取或修改 EH 登录状态，也不会保存查询历史。

# 登录与里站

## `igneous` 失效或显示 `mystery`

如果出现“错误的 igneous”、无法进入里站，或者身份 Cookie 中的 `igneous` 显示为 `mystery`，请按以下步骤重新登录：

1. 在应用中退出登录。
2. 连接稳定的欧美 VPN 节点，并在整个登录过程中保持同一个节点。
3. 重新打开应用，通过网页登录进入 E-Hentai 表站并完成登录。
4. 登录完成后，在“设置 → EH → 画廊站点”中切换到 `exhentai`。
5. 如果仍然失败，请再次退出登录，确认 VPN 节点后重复以上步骤。

`igneous` 可能会过期，过期后需要重新登录获取。身份 Cookie 属于账号敏感信息，请勿截图、公开或发送给他人。
