# “更新与支持”页面内容

这份文档用于集中修改 Android 应用中“设置 → 更新与支持”页面的内容。

## 编辑规则

1. 只修改表格中的“修改后内容”列，不要修改“字段 ID”。
2. “修改后内容”留空表示保持当前内容不变。
3. 在页面条目标题对应的“修改后内容”中填写 `[隐藏]`，表示隐藏整个条目，并在回填时移除不再使用的点击逻辑。
4. 普通文字字段填写 `[隐藏]`，表示隐藏该文字或对应控件。
5. 多行文字请在同一个单元格中使用 `<br>` 换行，避免破坏 Markdown 表格。
6. 如果需要新增当前文档中没有的条目，请写在文末“其他调整说明”中。

- 当前 `versionName` 为 `2.0.2.4`。
- 当前 Debug 构建的 `versionCode` 为 `117`。
